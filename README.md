# psyco-landing-page

## Propuesta V2 profesional

`index-v2-profesional.html` es la propuesta solicitada el 2026-11-24 para presentar el valor de Verdme de forma más rápida y objetiva. No reemplaza `index.html` ni el `index-v2.html` anterior.

- Primera pantalla: producto, audiencia, tres capacidades concretas, CTA y referencia al precio de Basic.
- Recorrido: gestión clínica, datos para RDA, cobros y finanzas, equipos, seguridad, planes y asesoría.
- Las secciones tienen altura natural y menos repetición; el ejemplo aprobado de pago se puede desplegar para explorarlo.
- Se reutilizan las vistas ilustrativas y los recursos incrustados de la landing actual. El checkout, las prestaciones y condiciones de Basic y los contactos se conservan.
- RDA significa captura de datos de Paciente y Consulta Externa; no se promociona envío, aceptación o certificación de interoperabilidad.

La propuesta sigue siendo un HTML autocontenido. Sus estilos de composición están en `verdme-v2-professional`; conserva los estilos de origen de las vistas y del checkout para mantener esos ejemplos sin cambios. La fuente de verdad comercial sigue siendo `features.md`.

Validación de la propuesta: 360, 390, 768, 1280 y 1440 px, incluida una ventana de 1280 × 640 y zoom al 200 %. Sin desbordes ni textos recortados; menú, anclas, foco por teclado y ejemplo desplegable comprobados. El checkout conserva el mismo HTML y los mismos estilos internos al compararlo con igual escala exterior. Revisión independiente de diseño y copy aprobada.
