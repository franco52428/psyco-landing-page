# Manifiesto de snapshot

## Fuente

- Prototipo estático Verdme, snapshot de trabajo posterior a la implementación de Agenda / Calendario.
- Punto recuperable anterior al calendario: `verdme-before-agenda-calendar-v1`.
- Este paquete no incluye el repositorio de producción de Psyco ni pretende modificarlo.

## Módulos incluidos

| Módulo | Estado del mock |
| --- | --- |
| Pacientes | Directorio, ficha y tres secciones de información. Referencia visual principal. |
| Procesos clínicos | Lista, elemento dossier, cabecera y secciones mock. |
| Agenda · Sesiones | Lista con filtros funcionales sobre datos mock. |
| Agenda · Calendario | Vista semanal mock con selector de fecha y navegación. |

## Recursos incluidos

- `prototype/brand/`: lockup temporal Verdme.
- `prototype/avatars/`: banco PNG de hojas de pacientes.
- `prototype/process-assets/`: dossier/señal de proceso.
- `prototype/art/`: cabecera contextual botánico-tecnológica.

## Seguridad de implementación

Los recursos PNG son arte visual de referencia. No reemplazan los SVG operativos exigidos para iconografía de sistema. La fuente y los iconos de producción siguen pendientes según el brief incluido.
