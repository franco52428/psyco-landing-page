# Dirección UI Verdme v0

## Intención

Producto clínico humano, sobrio y claro. La botánica aporta identidad, no decoración permanente. La capa tecnológica se expresa mediante estructura, orden, señales y retículas sutiles; nunca mediante estética genérica de IA.

## Principios

- Light-first: fondo cálido muy claro, superficie blanca y lectura extensa cómoda.
- Una sola familia de tipografía para todo el producto.
- Verde bosque como acción y señal, no como relleno dominante.
- Líneas finas antes que sombras o tarjetas pesadas.
- Radios moderados; evitar pastillas y módulos innecesarios.
- Iconografía lineal, terapéutica y funcional; no botánica para cada acción.

## Aplicaciones actuales

| Superficie | Decisión visual |
| --- | --- |
| Pacientes | Hojas suaves y transparentes como viñeta individual; detalle en blanco, cubierta contextual sutil. |
| Procesos | Dossier/señal estructurado para diferenciarlo de la persona; cabecera de retícula tenue. |
| Agenda | Lista agrupada por días y calendario semanal minimalista; datos en primer plano. |
| Desplegables | Filas lineales, títulos claros, subtítulos de apoyo y divisores finos. |

## Evitar

- Fondos hospitalarios, negros puros, morados por defecto y saturación corporativa.
- Flores, ornamentos o ilustración botánica repetida.
- Sombras pesadas, tarjetas financieras o dashboard genérico.
- Tipografías diferentes por módulo.
